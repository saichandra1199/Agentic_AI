# 🗺️ Trip Planner

A simple yet powerful AI-powered trip planning tool that creates personalized travel itineraries based on your preferences and budget.

## 🚀 Features

- Plan trips with custom start and end locations
- Set budget range (Low/Mid/High)
- Specify number of travelers
- Include your interests (e.g., adventure, culture, food)
- Get a detailed day-by-day itinerary
- Budget breakdown and allocation

## 🛠️ Setup

1. **Clone the repository**
   ```bash
   git clone [https://github.com/saichandra1199/Agentic_AI.git](https://github.com/saichandra1199/Agentic_AI.git)
   cd Agentic_AI

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt

3. **Setup OPENAI KEY**
   ```bash
   export OPENAI_API_KEY=your_api_key

4. **Run the application**
   ```bash
   python main.py
